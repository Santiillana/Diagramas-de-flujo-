# Referencia funcional original

\`diagramas_de_flujo_original.html\` es una copia de referencia del prototipo entregado para el rediseño.

- No editar este archivo para desarrollar la nueva aplicación.
- Mantenerlo byte por byte para que las comparaciones futuras sean reproducibles.
- Usarlo para auditar controles, contenidos, pseudocódigo, recorridos y funciones originales.
- Abrirlo desde el enlace **Abrir prototipo original** de la nueva interfaz.
- No declarar una función migrada hasta tener una equivalencia nueva comprobada.

La nueva aplicación vive en \`index.html\` y \`src/\`.
